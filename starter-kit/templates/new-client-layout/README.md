# New Client Folder Layout

Copy this whole folder for each new client and rename it, e.g.
`maple-lane-pet-grooming/` (a made-up business).

```
<client-name>/
  config/     business details: hours, services, contacts (no secrets)
  prompts/    the client's filled-in prompt templates
  knowledge/  FAQs and reference notes the assistant may use
  logs/       conversation logs kept for review (made-up data in tests)
  notes/      onboarding notes and test results
```
